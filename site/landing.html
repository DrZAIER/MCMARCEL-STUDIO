McMarcel — Multi-Country Model Application for RSV Cost-Effectiveness Policy — is the static monthly birth-cohort model of respiratory syncytial virus prevention built at CHERMID (Centre for Health Economics Research & Modelling Infectious Diseases, University of Antwerp). It asks what maternal vaccination and monoclonal antibodies are worth in a given country, and it was first applied to 72 Gavi-eligible countries. McMarcel Studio is the rewrite of that model: a Rust engine, a guided interface, a local database, and an evidence gate that refuses to present synthetic numbers as a country estimate.

The study this Studio is built on

The original study

McMarcel for 72 Gavi countries

The framework was conceived to evaluate maternal and neonatal RSV immunisation strategies across 72 Gavi-eligible countries. That release is archived on Zenodo and carries the model implementation together with the country inputs.

Read before you use the numbers

Perturbed public-release inputs

To publish the methods without the confidential data, the Belgian input files carry non-systematic noise; the perturbed files are marked with an X (BELX, ESPX, RESCEUX).

Every affected parameter is therefore marked SYNTHETIC in the Studio, production mode stays blocked and every run is stamped. The outputs reproduce the model faithfully while staying epidemiologically non-actionable.

The evidence model

What the Studio aims to do

01 · Belgium

Reproduce the reference case

The Belgian base case is the regression target: the R implementation reproduces it byte-identically, and the Rust engine has to match it within a documented tolerance. The comparison found and fixed two real defects — the maternal vaccine was inheriting the monoclonal antibody's catch-up coverage, and the cost-effectiveness layer mislabelled the frontier of a ten-scenario comparison.

The reference case

02 · Gavi

Carry the study to the Gavi countries

The 58 countries eligible for Gavi support in 2020 each get a pack: the life table from the UN World Population Prospects 2019, the number of births, the life expectancy and the GDP per capita are derived and carry their source; everything that needs country evidence stays MISSING, so the production gate keeps the pack closed until an analyst fills it in.

How the countries are handled

03 · New packs

Build a country pack from the questionnaire

Seventy-seven parameters in seven sections, each with its definition, its unit, why it matters, how to source it and the evidence status that fits. Fill it in in the browser, export it, and it becomes a country pack with full provenance: no value without a source, no production run without evidence.

Run it

The application

The engine runs on your machine; the data never leaves it.

git clone https://github.com/DrZAIER/MCMARCEL-STUDIO.git
cd MCMARCEL-STUDIO
cargo build --release
cd ui && npm install && npm run build
cargo run --release -p mcmarcel-server

Then open http://127.0.0.1:8787, or build the desktop shell with cargo build --release --manifest-path src-tauri/Cargo.toml.

What this site is, and what it is not

This site is the static part of McMarcel Studio: the documentation, the questionnaire toolkit and the published reference results. The application itself is a local-first desktop program — the Rust engine, the SQLite store and the production gate run on your machine, which is what keeps a country pack under the analyst's control. That is also why a hosted copy of the engine is not offered here: a model whose inputs leave the machine is a different product with different obligations.
